# Quotient geometry for correlation matrices

This repo contains the code for the following paper.

Chen, H. (2025). Quotient Geometry of Bounded or Fixed-Rank Correlation Matrices. SIAM Journal on Matrix Analysis and Applications, 46(1), 121-150. 

### Main Files

- geomcorr.py contains the basic functions related to the quotient geometry of correlation matrices.
- correlation.ipynb contains the experimental results
